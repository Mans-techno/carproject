# Осенняя трасса

3D-гонка в браузере на three.js: открытый мир 5×5 км, 29 машин, гараж, пауза, очки навыков.

Модели машин — авторы и лицензии указаны в гараже (в основном CC BY 4.0 с Sketchfab; некоторые CC BY-NC — только некоммерческое использование).
Текстуры и деревья — Poly Haven (CC0). Небо — HDRI Poly Haven (CC0).
